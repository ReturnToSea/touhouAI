# Results

**Nothing here yet.**

This page is reserved for results from the current plan —
[generative danmaku via the ECL VM](ecl-vm.md). That work has not started
producing numbers, so there is nothing to report.

The plan's own success criteria are defined in
[Chapter 13, Stage C](ecl-vm.md#stage-c-integration): a policy trained on
VM-generated Letty must **beat the replay baseline** on the real game (~100 s
active-fight median, ~15 % real kill-rate). When that gate passes, the numbers
land here.
